# zhixian-slides

技术分享 slides 合集，使用 Slidev 构建。

## 链接

- **站点**: https://slides.zhixian.io
- **GitHub**: https://github.com/zhixianio/zhixian-slides
- **Cloudflare Pages**: zhixian-slides

## 部署

```bash
npm run build
wrangler pages deploy dist --project-name=zhixian-slides
```

## 新建 deck

```bash
npm run new
```

## 本地开发

```bash
npm run dev
```
